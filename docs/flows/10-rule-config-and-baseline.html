Rule configuration cache

flowchart LR
    DB[("aml_rule
threshold, window, weight, params JSON")] -->|findByActiveTrue| RC["RuleCacheServiceImpl.refreshRuleCache()"]
    T1["ApplicationReadyEvent"] --> RC
    T2["@Scheduled every 5 min"] --> RC
    T3["POST /api/v1/detection/rules/reload"] --> RC
    RC -->|"parse params, build Map, then rules = Map.copyOf(...)"| V["volatile Map of RuleConfig"]
    V -->|getActiveRules| E["DetectionEngine"]

The whole map is swapped in one write, so a consumer never sees a half-built rule set.

Nightly baseline

sequenceDiagram
    autonumber
    participant T as Scheduler 00:30 UTC / POST baseline/recompute
    participant B as BaselineJob
    participant W as RedisSlidingWindowStore
    participant R as Redis
    T->>B: runNightly() / recomputeAll()
    B->>W: activeAccounts()
    W->>R: SMEMBERS aml:accounts:active
    loop each account
        B->>W: dailyTotals(acct, today-90, today-1)
        W->>R: pipeline HVALS aml:day:{acct}:{day} x 90
        B->>B: average over days with activity
        B->>W: putBaseline(acct, avg, 3 days)
        W->>R: SET aml:baseline:{acct}
    end
