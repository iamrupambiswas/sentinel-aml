sequenceDiagram
    autonumber
    participant C as Client
    participant G as Gateway

    participant D as detection-service

    C->>G: POST /api/v1/transactions (Idempotency-Key)

    I->>R: SET idempotency key NX
    I->>DB: INSERT transaction + outbox_event
    I-->>C: 202 Accepted (transactionId)
    I->>DB: OutboxPoller reads PENDING (every 200 ms)
    I->>Q: TransactionIngestedEvent
    Q->>D: TransactionConsumer
    D->>R: sliding windows (Lua)
    D->>Q: RuleHitsDetectedEvent (if any rule fired)
