Step by step

  1. The client calls the gateway on port 8080. It is the only port external clients should use.
  2. RequestLoggingFilter logs ▶ [REQ] / ◀ [RES] / ✖ [ERR] and forwards an X-Trace-Id header (reused by every service's LoggingAspect, so one id follows the request across logs).
  3. Spring Cloud Gateway Server MVC evaluates the Path= predicates of each route in order.
  4. The first matching route forwards the request, unchanged, to its uri. The URI comes from an environment variable with a localhost default (12-factor).
  5. The downstream response (status, headers, body) is streamed back to the client.
