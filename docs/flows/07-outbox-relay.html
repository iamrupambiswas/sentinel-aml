Ingestion

Outbox relay & event contract

How rows written in the business transaction become ActiveMQ messages without being lost, and what those messages contain.

Step by step

  1. Every 200 ms, OutboxPoller.processOutboxEvents() loads up to 500 PENDING rows, oldest first (index idx_outbox_status_created).
  2. Each payload is deserialized into TransactionIngestedEvent and sent with JmsTemplate.convertAndSend(MessagingConstants.TRANSACTION_QUEUE, event).
  3. The shared converter writes JSON text and sets the _type property to the logical name TransactionIngested.
  4. Sent rows are marked PUBLISHED with published_at; the status updates commit when the method returns.
  5. A payload that can never be parsed is marked FAILED. A broker error stops the tick and leaves the remaining rows PENDING, in order.
